## Dataset Summary

Synthetic Traditional Chinese (Taiwan) spoken-language NLU data for joint intent
classification and slot filling, generated from a 20-shot-per-intent seed drawn
from MASSIVE `zh-TW`.

- **Task:** intent classification (60 classes) + slot filling (55 slot types)
- **Language:** `zh-Hant-TW`
- **Planned release size:** filtered 8,000–10,000; not yet generated
- **Completed pilot:** 500 unfiltered; 437 pass F1–F4; F5/F6 not calibrated
- **Generated by:** `qwen3.6:27b` running locally via Ollama
- **API cost:** $0

## Supported Tasks

The intended uses are supervised intent classification, slot filling, joint NLU,
and controlled comparisons of real-only versus synthetic-data training. It is not
a dialogue corpus, general-purpose language-model pretraining corpus, or source
of factual Taiwan knowledge.

## Dataset Structure

### Data fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Stable content-addressed identifier |
| `utt` | string | The generated utterance |
| `intent` | string | One of the 60 MASSIVE intents |
| `slots` | list of `{type, value}` | Slot type must be one of 55; value must be groundable in `utt` |
| `style` | string | `massive_like` or `tw_colloquial` — see "Style axis" below |
| `provenance` | object | Recipe, model, prompt version, seed sample id, filter scores, reject reason |

### Splits

This dataset is **training data only**. It contains no validation or test split
by design — evaluation is always done on the untouched real MASSIVE `zh-TW`
Val/Test.

### Two versions

| Version | Contents |
| --- | --- |
| `filtered` | Planned release of samples that pass all seven filter gates |
| `unfiltered` | Planned release of all generated samples, including rejected ones |

Both are planned for release after the production gate. The rejected samples are
informative because they show what the filter pipeline actually catches.

## Dataset Creation

### Source data

MASSIVE (`AmazonScience/massive`, `zh-TW` config), CC BY 4.0. Seed set is
`min(20, available)` samples per intent drawn from the **train** split with
`seed=42`. The frozen manifest (with source SHA256 and exact per-intent counts)
is published at `splits/manifest.json`.

### Generation recipes

| Recipe | Description | Count | Share |
| --- | --- | --- | --- |
| `paraphrase` | Meaning-preserving rewording | 175 | 35% |
| `slot_substitution` | Procedural slot replacement followed by rewriting | 150 | 30% |
| `noise_codeswitch` | Taiwan colloquial, ASR-like, and bounded code-switch variation | 100 | 20% |
| `hard_negative` | Confusable wording that must retain the planned label | 75 | 15% |

These are pilot counts, not release counts. Pilot styles were 201
`massive_like` and 299 `tw_colloquial`.

### Style axis

MASSIVE `zh-TW` is translated from English SLURP, so its register skews toward
translationese. Samples are therefore tagged `massive_like` (close to the source
register) or `tw_colloquial` (natural Taiwanese speech, code-switching, ASR-like
noise). The mixing ratio is a recorded design parameter, not an accident.

### Filtering pipeline

The 500-sample pilot passed schema validation for all 500 rows. After the frozen
label contract and grounded-slot checks, 454 remained; after locale checks, 437
remained. Rejections were 21 label-contract violations, 25 ungrounded or
overlapping slots, 13 simplified-Chinese violations, and 4 language-ratio
violations. The independent judge accepted 49/50 sampled rows.

F5/F6 use local-only BGE-M3 dense embeddings. Thresholds were frozen only after
the similarity distributions, figure, and top/bottom pairs were reviewed:
0.999 synthetic duplicate, 0.995 seed copy, 0.650 seed outlier minimum, and
0.990 Val/Test contamination. The final pilot retained 375/500 (75.0%);
semantic rejects were 16 synthetic duplicates, 33 seed copies, 1 outlier, and
12 Val/Test near-duplicates. The Wilson 95% lower yield bound is 71.02%.

### Annotations

Labels are **generated automatically** by the pipeline — no manual per-sample
annotation was performed. For the `slot_substitution` recipe the labels are
produced *procedurally* (slot values are substituted by program before the model
rewrites the sentence), so the ground truth does not depend on the model at all.
Human involvement was limited to spot-checking 20 samples for observation.

## Considerations for Using the Data

### Contamination and leakage

- The generator never read the validation or test split. Seeds come only from the
  frozen 20-shot train manifest.
- Decontamination against Val/Test was **exclusion-only**: near-duplicates were
  removed, and Val/Test were never used to rank, weight, or select anything.
- The planned decontamination audit log records removed ids, similarity scores,
  and matched evaluation ids; it will be released alongside the dataset.

### Known limitations

- Inherits any biases and Taiwan-specific knowledge gaps of the teacher model.
- Synthetic utterances are seeded from a 20-shot sample; coverage of rare intents
  and rare slot types is correspondingly thin.
- No per-recipe ablation was run (see `docs/DECISIONS.md` D-004).
- The pilot's cheap filters rejected 63/500 rows; one additional incomplete
  request escaped those filters and was rejected by the independent judge.
- The original 18,000-row plan projected to 6.44 GPU hours and was rejected.
  The frozen-yield calculation instead released 11,264 rows, projected at 4.028
  hours and conservatively sized to retain at least 8,000 rows.

## Licensing

### Model roles

Three models are involved, deliberately drawn from **three different families**,
all under Apache-2.0. Cross-family distillation rules out the "the teacher and
the student are the same family, so of course it works" objection.

| Role | Model | Family | License |
| --- | --- | --- | --- |
| Teacher (generates the data) | `qwen3.6:27b` | Qwen | Apache-2.0 |
| Judge (audits pilot) | `gpt-oss:20b` | gpt-oss | Apache-2.0 |
| Student (fine-tuned on the data) | `google/gemma-4-E4B-it` | Gemma 4 | Apache-2.0 |

### License table

| Component | License |
| --- | --- |
| Seed utterances (MASSIVE `zh-TW`) | CC BY 4.0 — attribution required |
| Teacher model | Apache-2.0 — no restriction on use of outputs |
| Generation / filtering code | MIT |
| **This synthetic dataset** | CC BY 4.0 (planned; retains upstream attribution) |
| Released LoRA adapter (separate repo) | Apache-2.0, inherited from the student base model |

Because the seed utterances are CC BY 4.0, derivative synthetic data carries the
attribution obligation. The teacher model is Apache-2.0, which places no
restriction on the use of its outputs. Note that the **dataset's** license is
determined by the seed data and the teacher only — the student's license governs
the published adapter, not this dataset.

## Cost and reproducibility

Generated entirely on a single RTX 4090 (24 GB) on native Windows. **No API
spend.** The completed M2–M4 measured work used 0.292 GPU hours. Pilot generation
used 643.73 seconds and the final adopted judge pass used 88.37 seconds; diagnostic
judge attempts are retained separately. Electricity and commercial-API
equivalents are not reported because no defensible measurement was made.
